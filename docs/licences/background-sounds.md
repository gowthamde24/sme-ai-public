# Background sounds: where every one comes from (C1, 25 Nov 2026)

Rule (owner, 24 Nov): only CC0 or own-made audio; every source listed here; anything that needs a paid asset is the owner's decision.

| id | what it is | source | licence |
|---|---|---|---|
| `off` | no sound | none | none |
| `quiet_office` | a low hum with a slow swell | own-made: seeded filtered noise, `services/ai-api/app/telephony/ambience.py` `placeholder()` | none needed (generated by our code, no recording) |
| `shop` | a brighter murmur with now-and-then bumps | own-made, same function | none needed |
| `busy_office`, `call_centre`, `market`, `showroom`, `clinic_reception`, `home`, `street` | seven more beds, each a different mix of hum, murmur, clicks and swells | own-made, same file, table `RECIPES` | none needed |

How they are made: `scripts/make_ambience_placeholders.py` writes the nine `.pcm` beds (8 kHz, 16-bit mono, seeded, byte-for-byte repeatable); `scripts/make_background_previews.py` turns each into a 6 s seamless loop preview mp3 (`previews/<id>.mp3`, 16 kHz, 32 kbps, ffmpeg + libmp3lame, a tool of ours, not third-party audio). No third-party recording is in the repository. No paid asset is used.

**Honest limit:** these are synthetic beds. A real recording of a call centre or a market sounds more real than filtered noise. Replacing any one with a CC0 or own recording is a file swap (same name, `.pcm` 8 kHz mono, at least 2 s, and its preview), with no code change; add its source, the author and the licence to the table above in the same change. Whether to do that, or to buy a licensed set, is the owner's decision.
