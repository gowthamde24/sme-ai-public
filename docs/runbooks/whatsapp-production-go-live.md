**Principle:** nothing reaches a customer until FOUR things are all true: the secrets exist, the fence holds only numbers he approved, the templates are approved by Meta, and the platform sending switch is ON. Each can be undone alone (section 8).

## 1. The three secrets (owner, his Terminal, nothing shown on screen)
`deploy/prod-secrets-prompt.sh` already has the three slots: `sme-whatsapp-token` (prompt, hidden), `sme-whatsapp-app-secret` (prompt, hidden), `sme-whatsapp-verify-token` (generated by the script; it shows it only when he asks, because he pastes it into Meta once in step 6). He presses Enter to skip any that exist.

## 2. The five lines in `deploy/.env.production` (owner or C1 with him; local file, never in git)
```
WHATSAPP_APP_ID=<App ID>
WHATSAPP_EMBEDDED_CONFIG_ID=<configuration ID>
WHATSAPP_EMBEDDED_VERSION=v5
WHATSAPP_ALLOWED_RECIPIENTS=+91XXXXXXXXXX,+91YYYYYYYYYY
```
(the fence: ONLY these two numbers can ever receive a message while the line is set).

**Safety facts (tested):** an UNSET fence in the adapter means "no fence" (it would message anyone), an EMPTY one means nothing is sent. The API deploy therefore READS the fence from `deploy/.env.production` and STOPS if it is empty or missing (`tests/test_production_slice.py`), so the API can never run without a fence; the worker sends an empty fence when the line is absent (nothing goes out). Widening the fence is a reviewed change plus his written word.

## 8. Sending switch and the test (owner's run-it, in this order, only when the five templates say "approved" in the app)
1. `select app.operator_set_outbox(true);`  (check: `select key, enabled from public.platform_flags where key = 'outbox_enabled';`). Until this statement the app says "Sending is stopped".
2. Test to the FENCE only: in the app create a test enquiry with his own number; the thank-you (`lead_ack`) arrives on his phone within a minute; reply "call me"; the lead shows "asked to be called". A number outside the fence is refused with a plain reason in the message list (it never reaches Meta).
3. Wait for the shop owner's number to receive the same. Only then is the fence widened by a reviewed PR and HIS written word, never earlier.
**Undo, each alone and immediate:** `select app.operator_set_outbox(false);` stops everything; unset `PROD_WHATSAPP` and redeploy the worker; `deploy/production.sh rollback sme-api --execute`; Meta side: remove the webhook subscription.
