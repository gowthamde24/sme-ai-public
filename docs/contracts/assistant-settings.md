# Settings > AI assistant: the API contract (job DM, C1 part)

**Status: the shapes are final; the endpoints are built on branch `api/dm-outcomes-trial-assistant`.** Build against `packages/contracts/assistant_settings.examples.json` (generated from the real service; validated against the schema by a test). Files (generated by `make contracts`): `assistant_settings.schema.json`, `assistant_settings.ts`.

| Method and path | Who | Answer |
|---|---|---|
| `GET /v1/tenants/{tenant_id}/ai-assistant` | Owner, Admin | `AssistantOut`: `settings` (what is saved, or the **defaults of the business type** before the first save), `saved`, `defaults` (for "reset to defaults"), `business_name`, `business_type` (the pack's code), `intro` (the fixed introduction per language), `voice_notes_follow`, `options` (the four voices with, per language, `available` and `synthetic`; the styles; the languages in their own script), `locked`, `updated_at`, `wording: "draft"` |
| `PUT /v1/tenants/{tenant_id}/ai-assistant` | **Owner, second factor** | body `AssistantSettings` (every field, always) -> `AssistantOut`. 422 for a bad value; 422 `locked_for_business_type` for a school asking what it may not |
| `GET /v1/tenants/{tenant_id}/ai-assistant/preview?language=te&style=warm[&name=Vani]` | Owner, Admin | `PreviewOut`: one sample line with the shop's name and the assistant's name (the unsaved `name` too). It always states "AI assistant" |
| `POST /v1/tenants/{tenant_id}/ai-assistant/test-call` | Owner, second factor | `TestCallOut`: a **simulation** until telephony exists (`mode: "fake"`, a transcript, the outcome it would record). No call, nothing sent or stored |

`AssistantSettings`: `name` (1 to 24 characters, no `< > { } @ / \\ |`; "AI assistant" is **not** part of it: the introduction always says it), `voice_persona` (`female_warm | female_clear | male_calm | male_lively`), `main_language` (`te | hi | kn | en`), `auto_switch_language`, `allow_english_mixing`, `style` (`warm | respectful | quick`), `speed` (0.75 to 1.25 in steps of 0.05), `may_answer_prices`, `may_book_visits`, `may_send_media`, `may_talk_dues`, `max_discount_percent` (0 to 50), `handover_owner_asked`, `handover_upset`, `handover_order_above_paise` (paise, or null = off), `call_days` (Monday = 1 to Sunday = 7), `call_from_minute` and `call_to_minute` (minutes after midnight, steps of 15, 540 = 09:00 to 1260 = 21:00).

**The school rule (owner, 25 Oct 2026):** for an education workspace `locked` is `{may_talk_dues: false, may_answer_prices: false, max_discount_percent: 0, handover_order_above_paise: null}`: the assistant never discusses dues, fees or marks on calls or chats, offers no discount and has no order limit. Draw those switched off; the API refuses anything else. Fee reminders and marks messages go only as fixed template messages from the school's records.

A save also sets the speed, the calling hours and the persona's voices of the business's **voice notes** when it has them (`voice_notes_follow`). All wording (samples, introductions) is a **draft for native review**.
