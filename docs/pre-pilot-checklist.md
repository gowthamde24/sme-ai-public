# Pre-pilot checklist

Every risk, limit or deferred item recorded in the ADRs, in one place. Nothing here blocks local development. Each item has a **gate**: the point by which it must be closed or consciously accepted in writing.

**Phase** (the last column, added 2026-10-05 with the local-first decision, ADR 0017; sequence in `docs/plans/roadmap.md`): **Next ticket** (T007 and what it needs), **Before deploy** (before anything runs on a hosted project: the Customer Zero stage, T012), **Before real data** (before any real person's data enters; the real-data gate stays closed until then), **Later** (external pilot, scale, scheduled agents, outreach, ongoing hygiene), **Done**. The older **Gate** column is kept as the history of why a row exists; where the two differ, Phase is current.

Original gates: **T003** (before the next ticket builds on tenancy), **Pilot data** (before any real customer data is imported, per `docs/product.md`), **External pilot** (before a second, external tenant), **Scale** (before volume or a public launch).

Status key: `[ ]` open, `[x]` done. Add the ticket or ADR that closed it. Add new items as ADRs are written.
