# ADR 0096: a read-only workspace switches its controls off on every screen (job DP part 2)

Status: accepted (owner decision of 25 Oct 2026: when the trial ends unpaid the workspace is read-only: view and export only). The API refuses every change then (403 `workspace_read_only`, C1 part 3); this is the web's half.

## Decisions
1. **One read, one notice.** The workspace's layout reads `GET /billing/access` (any member, once per request: `readAccessCached`). When it says `read_only` it draws ONE notice at the top of every screen (`ReadOnlyBanner`: what is off, the dates the API gives, "write to billing@stack19.com") and leaves out the Ask dock. A read that fails counts as "full": the API refuses the change anyway, so the worst case is a button that says so when pressed.
2. **One scope, not 90 edits.** `ReadOnlyScope` (client, no markup) switches off, inside the page's own part of the frame, every control that changes something: the main button of the app (`btnMain` now carries the class `write-ctl`), any submit button, and anything marked `data-write` (a container switches off every control inside it: a Today card, an Outbox row, a visit card, the assistant's question line, the assistant's settings form). Links are never switched off except a main-button link (it gets `aria-disabled` and cannot be followed). It watches the page, so a list that loads later is covered, and it puts everything back when the person goes to a screen that keeps its controls or the workspace is paid. Each switched-off control carries the one sentence as its tooltip.
3. **What stays.** Looking, filtering, opening, exporting. A region marked `data-read-ok` is never touched, and these screens are not touched at all: Plans, Privacy, Suppression, Help and the Settings parts Data, Plan, Privacy, Security and Language (they are about the person or the data, never a change to the business).
4. **Paying again.** The notice has a slot for a button (`resume`); it is empty until C1's `POST /billing/resume` exists (job DP part 3 of C1). Until then the way on is the billing address.
