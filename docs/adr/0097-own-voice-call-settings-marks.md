# ADR 0097: the assistant's call settings, the owner's own voice and marks to parents (job DP part 3)

Status: accepted (owner decisions of 25 Oct 2026: schools make no sales or dues calls; the platform never stores a child's marks; an own voice only with the owner's spoken consent). Built against C1's contracts (`contract-call-settings.md`, `contract-own-voice.md`, `contract-marks-messages.md`); each screen has its own flag because the APIs ship separately: `CALL_SETTINGS_SCREENS`, `OWN_VOICE_SCREENS`, `MARKS_SCREENS` (off by default; `mock` = fake data, nothing sent; `1` = the API).

## Decisions
1. **Advanced call settings** are a closed `<details>` under Settings > AI assistant (Owner only): trying again, on the line, names and words, when it calls, safety, hand-over by topic, memory and purposes. The API's snake_case shape is the screen's own, so there is no mapping; every range of the contract is checked on the way in and out (`lib/call-settings/types.ts`). A school sees the calls it may not make switched off with the reason, never as a choice. The names and numbers of hand-over people are shown to the Owner only.
2. **Own voice** is a card under the assistant: name -> the fixed sentence from the API -> record the sentence and a 15 to 60 second sample (or choose a file for the sample), listen to both, create (second factor). The recordings go in ONE JSON body (base64) through the route handler `own-voice` (the browser never holds the token); nothing of them is shown again, and the mock keeps only the name and the time. "Delete my voice" asks once, says what goes, and needs the second factor. `own_voice` becomes a choice among the voices only while a voice is ready. The card says plainly that the assistant still says it is the AI assistant.
3. **Marks to parents** (a school, Owner and Admin open it, only the Owner sends): the file is chosen in the browser, sent to the preview and, with the preview's SHA-256 and count, to the send; the server holds it in memory for that request only. The page says before anything is chosen: "Marks are not stored. The file is deleted after sending." Only a send log stays (counts and a time; no marks, no child's name). The route is `/marks`, reached from Students ("Send marks to parents"), and belongs to the Announcements menu item for the module guard.
4. **Landing:** "Calls in your own voice" is the fourth point of the Natural AI calls section, worded as early access.

## Left for the real contracts
The JSON examples of C1's three contracts come with C1's branches; the screens parse the shapes written in the contract documents and refuse anything else. The log of earlier marks sends reads only the fields it knows (`batch_id`, a time, `sent`, `failed`, `blocked`).
