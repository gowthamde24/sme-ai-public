# Google Sheets
Every new row of your sheet becomes a lead.
- 1 Open your Google Sheet. Put headings in the first row: name, phone, and what they asked.
- 2 In Extensions > Apps Script paste the snippet below and replace YOUR_ADDRESS. Run it once to allow it.
- 3 Add a trigger: run it on every new form submit or edit. New rows become leads.
function sendLead(e) { const sheet = e.source.getActiveSheet(); const row = sheet.getRange(sheet.getLastRow(), 1, 1, 3).getValues()[0]; UrlFetchApp.fetch('YOUR_ADDRESS', { method: 'post', contentType: 'application/json', payload: JSON.stringify({ name: row[0], phone: row[1], note: row[2] }), }); } Your lead address is made per job and shown on this page when the feature is on.
