# Send marks to parents
Upload one file, check what will be sent, then approve. Each parent gets a fixed message about their child.
{role=note} Test mode: nothing is sent. The preview is made from your file in this session.
{label="Marks are not stored. The file is deleted after sending."} Marks are not stored. The file is deleted after sending. The file is read once to show you the preview and once to send, and nothing of it is kept. Only a log stays: which parent got which message, and when. It holds no marks and no child's name.
