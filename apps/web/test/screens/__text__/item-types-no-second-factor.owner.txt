# Item types
Item types are the kinds of goods you quote, for example "Type A". Each line of a quote with typed prices uses one. A price outside the lowest and highest price only gives a warning when a quote is made. It never stops a quote. Changing a price range does not change quotes that are already made.
{label="Item types, in order"}
table "Item types, in order":
  | th Name | th Code | th Can be used | th Position | th Lowest price | th Highest price |
  | th Type C (not sold) | C | No, switched off | 0 | none | none |
  | th Type A | A | Yes | 1 | none | none |
  | th Type B | B | Yes | 2 | ₹500.00 | ₹4,000.00 |
{role=note} Changing item types needs your authenticator app. [Set it up on the Security page](/app/security) , then sign in again with its code.
